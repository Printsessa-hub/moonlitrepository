# The Moonlit Repository — Full Static Website

Upload the entire folder as-is to a static host.

Edit `index.html` for the homepage. Edit `assets/styles.css` for colors/design.
Add blog posts by copying files in `posts/`. Add translation chapters by copying
`translations/jade-sovereign/chapter-001.html` and adding links to the novel page.

Replace `your-email@example.com` in ama.html and submissions.html.

Palette:

#C9A6A6 Dusty Rose
